# 🎯 Adivina el Número

Proyecto desarrollado en **Kotlin** para la asignatura de **Programación Multimedia y Dispositivos Móviles (PMDM)**.

## 📋 Descripción

El programa genera un número aleatorio entre **1 y 100** y el usuario debe adivinarlo.

Después de cada intento, el sistema indica si el número secreto es mayor o menor que el introducido.

El juego finaliza cuando el usuario acierta el número.

## ✨ Funcionalidades

- Generación aleatoria de un número entre 1 y 100.
- Comparación de intentos.
- Contador de intentos.
- Validación de datos introducidos.
- Mensajes informativos para guiar al usuario.

## 🛠️ Tecnologías utilizadas

- Kotlin
- IntelliJ IDEA / Android Studio

## ▶️ Ejecución

1. Clonar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA o Android Studio.
3. Ejecutar el archivo `Main.kt`.

## 📸 Ejemplo de ejecución

```text
Introduce un número entre 1 y 100: 50
El número secreto es mayor.

Introduce un número entre 1 y 100: 75
El número secreto es menor.

Introduce un número entre 1 y 100: 63
¡Correcto! Has adivinado el número.

Has adivinado el número en 3 intentos.
```
